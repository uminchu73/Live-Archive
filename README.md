# Live Archive

## 📖 概要
リットリンクのようにテーマを選択でき、
スマホから簡単に更新できる参戦履歴サービスを作る。

## 🎯 最終目標
- スマホだけで更新できる
- テーマを変更できる
- URLで公開できる
- 将来的に誰でも使えるサービスにする
